# agent-golf

An analysis tool that checks how easily agents can navigate your repo.

A badly structured repo is expensive to run agents on, and a well-structured one is cheap. This skill scores your repo and tells you what to fix.

## Usage

```
Audit this repo with agent-golf.
```

You get a score out of 25, the top friction points, quick wins, and long-term fixes.

While agents work in your repo, the skill also guides them to navigate cheaply on their own.
